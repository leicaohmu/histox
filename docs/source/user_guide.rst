HistoX user guide
=================

The user guide explains HistoX as a connected pathology workflow: install the
library, organize a study, prepare whole-slide images, build datasets, train
models, and evaluate their evidence.

New to HistoX? Start with :doc:`installation` and :doc:`quickstart`, then
follow the chapters below in order.
