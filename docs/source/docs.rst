HistoX documentation
====================

HistoX is a PyTorch-first Python library for computational pathology. The
documentation is separated into task-oriented guides, API reference, developer
notes, and complete tutorials.

Stable and development documentation
------------------------------------

This site currently documents the development branch. APIs inherited from
HistoX remain available for compatibility, but examples are only considered
verified after they have been migrated to ``histox`` imports and executed in a
supported environment.

Start here
----------

* :doc:`installation` — install HistoX and choose optional dependencies.
* :doc:`quickstart` — run a minimal PyTorch-first pathology workflow.
* :doc:`user_guide` — learn projects, datasets, slides, models, and analysis.
* :doc:`methods` — browse method families, implementation status, and provenance.
* :doc:`api` — look up modules, classes, functions, and arguments.
* :doc:`developer` — extend HistoX and troubleshoot development workflows.
* :doc:`tutorials` — follow complete examples grouped by topic.
