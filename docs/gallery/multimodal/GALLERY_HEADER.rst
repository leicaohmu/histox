Multimodal pathology
====================

Combine whole-slide histology with molecular measurements and pathology
reports. These tutorials keep modality alignment, train-only preprocessing,
survival endpoints, and validation boundaries explicit.

The PS3 notebook begins with prepared patient-level features. Use
:doc:`Prepare multimodal inputs for PS3
</tutorials/ps3_data_preparation>` when starting from WSI files and report
text, or :doc:`Reproduce PS3 on TCGA COADREAD
</tutorials/ps3_coadread_reproduction>` for the complete benchmark protocol.
