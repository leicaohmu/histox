# HistoX documentation

HistoX is a PyTorch-first Python library for computational pathology. The
documentation is separated into task-oriented guides, API reference, developer
notes, and complete tutorials.

## Stable and development documentation

This site currently documents the development branch. APIs inherited from
HistoX remain available for compatibility, but examples are only considered
verified after they have been migrated to `histox` imports and executed in a
supported environment.

## Start here

- [Installation](installation.html) -- install HistoX and choose optional dependencies.
- [Quickstart](quickstart.html) -- run a minimal PyTorch-first pathology workflow.
- [HistoX user guide](user_guide.html) -- learn projects, datasets, slides, models, and analysis.
- [HistoX API reference](api.html) -- look up modules, classes, functions, and arguments.
- [Developer notes](developer.html) -- extend HistoX and troubleshoot development workflows.
- [HistoX Tutorials](tutorials.html) -- follow complete examples grouped by topic.
