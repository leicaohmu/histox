# HistoX formal identity assets — review set

## Source and ownership

- Source concept: user-supplied HistoX cellular-O-to-X design.
- Vector redraw: created for the HistoX project during Patch A3b.
- No Slideflow logo geometry or third-party brand asset is incorporated.

## Files

- `histox-mark.svg`: primary transparent compact mark for light backgrounds.
- `histox-mark-dark.svg`: transparent compact mark for dark backgrounds.
- `histox-mark-mono.svg`: monochrome fallback.
- `histox-wordmark.svg`: primary horizontal wordmark and tagline for light backgrounds.
- `histox-wordmark-dark.svg`: horizontal wordmark and tagline for dark backgrounds.
- `histox-studio-splash.svg`: 600 × 690 Studio launch screen.

## Palette

- Deep navy: `#071426`, `#0B1F3A`
- Cyan: `#21D4D8`
- Magenta: `#D84BCB`
- White: `#FFFFFF`
- Secondary copy: `#344054`, `#CBD5E1`

## Production notes

- Compact marks contain no text and use a square 512 × 512 viewBox.
- Wordmarks use an Inter/Arial/sans-serif font stack; raster exports should be generated in a controlled environment.
- SVG files contain no gradients, filters, linked images, scripts, or external resources.
- These are the approved HistoX identity assets introduced in Patch A3b.
